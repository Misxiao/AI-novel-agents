# 中文网文写作内置素材包

本目录承载项目内置的中文网文写作模块素材。它参考 `Tomsawyerhu/Chinese-WebNovel-Skill` 的模块化思路，转换为本项目可直接被 Agent、Workflow 节点和检索系统使用的结构化资源。

## 使用原则

- 这里的素材用于指导诊断、规划、生成、评审和修改。
- 素材只借结构、节奏、检查维度和模块职责，不要求复用任何原文句面。
- 每本小说使用素材时必须绑定 `novelId`，不得把小说私有记忆写入全局素材包。
- 平台不暴露素材配置页面；素材由代码和版本控制维护。

## 目录

- `source-manifest.json`：来源、导入策略和版权处理说明。
- `module-index.json`：模块索引和调用顺序。
- `module-packs/webnovel-writing-core.json`：内置模块规则包。
- `corpus/source-index.json`：外部语料源索引，不包含小说全文。

## 关于外部语料

原仓库包含大量小说正文、PDF 和 docx 示例，但未发现明确许可证文件。因此本项目不默认内置这些全文语料。若用户确认拥有使用权，可在后续实现导入器，将外部 checkout 或用户自有语料导入本地私有素材库。
